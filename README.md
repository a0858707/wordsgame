# 🧩 Crostic - Word & Cryptogram Crossword Puzzle Game

Полная реализация популярной игры-головоломки **Crostic** (акростихи и криптограммы со скрытыми фразами и цитатами) в соответствии со всеми требованиями ТЗ и скриншотами.

## 🌟 Ключевые возможности и механики

1. **Двусторонняя криптограмма (Cipher System)**:
   - Каждая буква в алфавите привязана к уникальному номеру.
   - Скрытая цитата / афоризм отображается вверху с номерами под каждой клеткой.
   - Список определений и слов-ответов (как в кроссворде) с номерами под каждой буквой.
   - При вводе буквы она мгновенно заполняется во всех связанных клетках шифра и в цитате, и в словах.
   - Возможность вводить буквы как через список слов, так и напрямую кликая по клеткам цитаты!

2. **Точное соответствие визуалу ТЗ и макетам**:
   - **Уровень 1 из ТЗ (Notebook Mockup)**:
     - Тайная цитата: *"BE HAPPY THIS MOMENT"* (Омар Хайям)
     - Подсказки из скриншота:
       - *Not girls* -> **BOY** (1, 8, 6)
       - *"___ Alone" film 1990* -> **HOME** (3, 8, 13, 2)
       - *Ache, hurt (syn.)* -> **PAIN** (5, 4, 11, 14)
       - *Be afraid of (n.)* -> **FEAR** (7, 2, 4, 9)
       - *The science of numbers* -> **MATH** (13, 4, 10, 3)
   - **Уровень 2 из ТЗ (Mobile App Mockup)**:
     - Цитата: *"ENJOY SIMPLE PUZZLES"*
     - Подсказки: *JULY*, *SIMPLY*, *SOME*, *UPON*, *SIZE*

3. **3 Темы оформления (Themes)**:
   - 📱 **Modern**: Современный дизайн в стиле мобильного приложения, пастельные акценты, мягкие тени.
   - 📝 **Notebook**: Реалистичный блокнот в полоску с рукописным шрифтом и цветным маркером (в точности как на левом макете).
   - 🌙 **Midnight / Dark**: Темная неоновая тема для комфортной ночной игры.

4. **Мультиязычность (English & Русский)**:
   - Полная поддержка английских и русских уровней (пословицы, русская классика: Достоевский, Пушкин, Бэкон, Ливий).
   - Динамическая смена виртуальной клавиатуры (QWERTY / ЙЦУКЕН).
   - Поддержка физической клавиатуры компьютера (печать букв, Backspace, стрелочки/Tab для навигации).

5. **Игровой баланс и фичи**:
   - 📅 **Daily Challenge**: Ежедневный уникальный вызов с календарем, серией побед (Streak 🔥) и кубком дня 🏆.
   - 💡 **Система подсказок**:
     - *Открыть букву* (10 монет)
     - *Решить целое слово* (25 монет)
     - *Очистить ошибки* (15 монет)
     - *Бесплатный ежедневный бонус* (+30 монет)
   - 🔊 **Синтезированное аудио (Web Audio API)**:
     - Щелчки клавиш, переливы нот при вводе, мажорный аккорд при завершении слова, победный фанфарный триумф (без внешних MP3-файлов!).
   - 🎊 **Праздничные эффекты**:
     - Анимация конфетти при победе (`canvas-confetti`).
     - Окно победы с раскрытием «Любопытного факта» о цитате или авторе.
     - Оценка от 1 до 3 звёзд ⭐.
   - 🎨 **Конструктор уровней (Level Creator)**:
     - Возможность создать собственный уровень Crostic со своей цитатой, вопросами и интересным фактом и сразу сыграть в него!
   - 💾 **Автосохранение**:
     - Прогресс уровней, введённые буквы, монеты, звёзды и серии сохраняются в `localStorage`.

## 🚀 Запуск проекта

1. Установка зависимостей:
   ```bash
   npm install
   ```

2. Запуск локального сервера разработки:
   ```bash
   npm run dev
   ```
   Сервер запустится на `http://localhost:3000/`.

3. Сборка для продакшена:
   ```bash
   npm run build
   ```
